Why does reversible heat equal T dS?

Use reversible cycles to construct a state function, then take its infinitesimal change.

1. Begin with the reversible-cycle result

Begin with the Kelvin–Planck statement of the second law, without assuming an entropy formula: a cyclic device cannot have as its sole effect extracting heat from one equilibrium reservoir and producing positive work. Carnot’s theorem follows by comparing a reversible engine with another engine run backward. In particular, all reversible engines between the same two reservoirs have equal efficiency:

ηA,rev = ηB,rev
The Carnot-theorem step

Run the more efficient engine forward and the less efficient one backward. Match their hot-reservoir heat exchanges and calculate the remaining heat and work.

Their common efficiency depends only on the reservoir temperatures. Thermodynamic absolute temperature is chosen so that a reversible engine has Qh/Qc = Th/Tc, with both heat symbols positive magnitudes. Hence

Qh/Th − Qc/Tc = 0

To extend this result beyond a two-temperature cycle, decompose a reversible cycle into infinitesimal Carnot cycles using nearby isotherms and reversible adiabats. Shared internal boundary segments are traversed in opposite directions, so their signed heat-over-temperature contributions cancel; the adiabatic segments carry no heat. In the limit only the original outside boundary remains:

∮ δQrev/T = 0

Heat is positive into the system. The local temperature can vary around the cycle, so T stays inside the integral. This result is established before defining entropy in this route; using an entropy inequality to justify it here would assume the state function we are about to construct.

2. Show why the reversible path does not matter

Choose two reversible paths from equilibrium state A to state B. Following path 1 forward and path 2 backward makes a reversible cycle. Therefore,

∫path 1, A→B δQrev/T − ∫path 2, A→B δQrev/T = 0

Both integrals have the same value. Although heat itself depends on the path, this particular weighted integral depends only on the two endpoint states.

3. Define the entropy difference

A path-independent integral defines the difference of a state function. We call that function thermodynamic entropy:

SR(B) − SR(A) ≡ ∫A→B, reversible δQrev/T dSR = δQrev/T δQrev = T dSR

Thus the last equation is a rearrangement of the entropy differential. The second law provides the deeper justification that the differential is a change in a state function; it is more than a consequence of the first-law energy balance.

4. Interpret the units and a short example

Entropy has units J K−1. For a reversible isothermal heat input of 60 J at 300 K,

ΔSR = Qrev/T = 60/300 = 0.20 J K−1

If the system temperature changes along the path, retain the integral with T inside it. Multiplying an entropy change by one temperature is valid for a constant-temperature reversible step or as a local infinitesimal relation.

5. Explain why reversibility matters

An irreversible process can produce entropy internally. For example, an isolated ideal gas freely expanding into a larger available volume receives no heat, but its equilibrium entropy increases. Consequently the actual heat in that process cannot be written as T dS.

Entropy remains a property of the equilibrium endpoints. Its change can be calculated along a hypothetical reversible path between them, even if the actual process is irreversible. The symbol dS is a state-function change; δQ denotes a path-dependent transfer.

Does zero heat transfer always mean zero entropy change?

Only a reversible adiabatic process necessarily has zero entropy change. An irreversible adiabatic process can generate entropy, so zero heat alone is insufficient.
