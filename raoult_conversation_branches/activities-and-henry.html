When do activity corrections or Henry’s law replace the ideal result?

Use a pure-liquid reference activity

μA = μA* + RT ln aA aA = γAxA pA ≈ γAxApA*

The last relation retains ideal vapour and negligible liquid-pressure corrections. For an ideal solution γA = 1. The activity coefficient uses the same pure-liquid standard state as the chemical potential.

Distinguish the dilute-solute reference

Henry model: pB ≈ KHxB as xB → 0

KH is a measured limiting proportionality constant for a solute in a particular solvent; it need not equal the pure-solute vapour pressure pB*. Different Henry-law conventions use concentration instead of mole fraction and consequently have different units.
