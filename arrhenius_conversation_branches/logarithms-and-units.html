Can we take a logarithm of a rate constant with units?

How should an Arrhenius plot be labelled?

Make the numerical convention explicit

ln(k/kref) = ln(A/kref) − Eₐ/(RT)

Choose kref with the same dimensions as k, for example 1 s⁻¹ for a first-order rate constant. The common shorthand ln k means the logarithm of the numerical value in a stated unit. A must have those same units.

Check which quantities depend on the unit choice

Switching from seconds to minutes adds the same constant to both logarithmic axes values and the fitted intercept. It does not change the slope versus 1/T or the activation energy. A ratio k₂/k₁ is dimensionless when both rate constants use the same definition and unit.
