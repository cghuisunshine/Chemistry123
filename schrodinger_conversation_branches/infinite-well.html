How do walls produce discrete energies?

What determines the allowed values of k?

Solve inside an infinite square well

Let V = 0 for 0 < x < L, with impenetrable walls. For positive E, define k² = 2mE/ℏ². The spatial solution inside is A sin(kx) + B cos(kx). The wall at x = 0 forces B = 0.

ψ(0) = ψ(L) = 0 sin(kL) = 0 ⇒ k = nπ/L, n = 1,2,…

Normalize and read the energy

ψₙ(x) = √(2/L) sin(nπx/L) Eₙ = n²π²ℏ²/(2mL²)

The probability integral over the well is one because the integral of sin²(nπx/L) is L/2. n = 0 would give the zero function and cannot be normalized. Doubling L divides every energy by four; the allowed energies arise from the equation together with the wall conditions.
