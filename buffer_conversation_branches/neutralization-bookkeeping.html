How should added strong acid or base be handled?

Can I use the original mixing amounts?

Do stoichiometry before equilibrium

Assume an initial buffer contains 0.100 mol HA and 0.100 mol A⁻. Adding 0.0200 mol strong acid first converts A⁻ into HA. The prepared amounts after neutralization are 0.0800 mol A⁻ and 0.120 mol HA.

A⁻ + H⁺ → HA pH ≈ pKₐ + log₁₀(0.0800/0.120) = pKₐ − 0.176

The common final volume cancels in this concentration ratio. Any dilution still affects buffer capacity and the size of subsequent equilibrium shifts.

Then check the buffer approximation

Using these amounts assumes the later weak-acid dissociation changes them by only a small fraction and activity effects are adequate. If the strong acid consumes all A⁻, the logarithmic expression with a zero denominator or numerator is not a physical solution. Solve the remaining acid/base equilibrium and any excess strong acid instead.

The same ratio can hide very different resilience

Two buffers can have the same acid/base ratio and pH while containing different total amounts. The more concentrated buffer can absorb more added acid before that ratio changes appreciably. pH is a state descriptor, whereas resistance to a perturbation requires additional concentration information.
