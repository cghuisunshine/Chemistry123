Weak-acid square-root approximation

Use equilibrium and material balance to derive [H⁺] ≈ √(Kₐc₀c°), and check when it is valid.

The equation and what it means

x = (−κ + √(κ² + 4κc₀))/2, where κ = Kₐc° If x ≪ c₀: [H⁺] ≈ √(Kₐc₀c°)

Use equilibrium and material balance to derive [H⁺] ≈ √(Kₐc₀c°), and check when it is valid.

Symbols and units. c₀, x: mol L⁻¹; c° = 1 mol L⁻¹; Kₐ and K_w: dimensionless activity constants; κ = Kₐc° has concentration units.

What can we start from?

  • Equilibrium. Kₐ = a_H⁺ a_A⁻/a_HA; in an ideal dilute solution aᵢ ≈ [i]/c°, where c° = 1 mol L⁻¹.
  • Balance. For initially pure HA at analytical concentration c₀, dissociation changes [HA] by −x and [A⁻] by +x.
  • Charge. If water autoionization is negligible, [H⁺] = [A⁻] = x.
Prerequisites

We assume basic university mathematics and physics: differentiation, integration, vectors, energy conservation, and elementary probability. The chemical definitions and thermodynamic premises are stated explicitly; an empirical rate law or model is not proved by rearranging it.

1. Build the equilibrium concentrations

Write [HA], [A⁻], and [H⁺] using c₀ and x.

[HA] = c₀ − x; [A⁻] = x; [H⁺] ≈ x

The last equality neglects the H⁺ contribution associated with water autoionization.

2. Substitute into Kₐ

Include the standard concentration c° so Kₐ remains dimensionless.

Kₐ = x²/[c°(c₀ − x)] x² + κx − κc₀ = 0, κ = Kₐc°

Mass balance provides c₀ − x rather than simply c₀ in the denominator.

3. Solve before approximating

Use the quadratic formula and select the physically meaningful root.

x = (−κ + √(κ² + 4κc₀))/2

This is the positive root within this equilibrium model. It provides a comparison for the approximation.

4. Make and verify the small-x assumption

Assume x ≪ c₀, solve, and state two checks after calculating x.

x ≈ √(Kₐc₀c°) Check x/c₀ ≲ 0.05 and x ≫ √K_w c°

The 5% rule is a practical tolerance for dissociation, not a fundamental law. The water check is separate.

Conditions and limits

  • There is no added acid, base, or common ion; ideal dilute-solution activities are adequate.
  • Water autoionization is negligible, and x/c₀ is small for the square-root approximation.

The quadratic is exact only within the stated dilute, negligible-water model. After solving, check x/c₀ and x ≫ √K_w c°; otherwise include the missing physics.

Common misconception

A small Kₐ guarantees the approximation at every concentration.

The relative change depends on Kₐc°/c₀. Very dilute solutions can violate both the small-x and negligible-water assumptions.

Check the result

For the stated example, pH ≈ −log₁₀(0.0010/1) = 3.00. At much lower c₀, repeat both validity checks.

For Kₐ = 1.0 × 10⁻⁵ and c₀ = 0.10 mol L⁻¹, the square-root estimate is 0.0010 mol L⁻¹. What is x/c₀?

0.0010/0.10 = 0.010 = 1%. At 25 °C this x is also much larger than 10⁻⁷ mol L⁻¹, so neglecting water is reasonable.
