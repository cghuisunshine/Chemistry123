Where does the weak-acid quadratic come from?

What equations determine all the concentrations?

Write independent constraints

For a solution prepared from pure monoprotic HA with no added ions, mass balance gives [HA] + [A⁻] = c₀. Electrical neutrality gives [H⁺] = [A⁻] + [OH⁻]. In the ideal dilute model acid equilibrium and water equilibrium complete the system.

Kₐ = [H⁺][A⁻]/(c°[HA]) Kw = [H⁺][OH⁻]/(c°)²

Neglect water as an explicit model reduction

If [OH⁻] is negligible relative to [H⁺], set h = [H⁺] ≈ [A⁻] = x. Then [HA] = c₀ − x and the acid equation becomes:

x² = κ(c₀ − x), κ = Kₐc° x = [−κ + √(κ² + 4κc₀)]/2

The other quadratic root is negative and cannot represent a concentration. The positive root automatically satisfies 0 < x < c₀.

Use a numerically stable equivalent root

x = 2κc₀/[κ + √(κ² + 4κc₀)]

Rationalizing avoids subtracting two nearly equal positive numbers when c₀/κ is tiny. This algebraic improvement does not repair a physical failure of the negligible-water approximation.
