Why does first-order decay give an exponential?

What physical model gives −dc/dt = kc?

Assume a constant probability per surviving molecule

Suppose each surviving A has probability k dt + o(dt) of disappearing during a short interval dt, independent of its age and of the number of other A molecules. This constant-hazard assumption is a model for unimolecular decay, not a consequence of stoichiometry.

N(t + dt) − N(t) = −kN(t) dt dN/dt = −kN

Convert molecule count into concentration

At fixed volume, c = N/(NAV), so c obeys the same equation. The survival probability f(t) obeys df/dt = −kf with f(0) = 1, giving f(t) = e−kt.

f(t + s) = f(t)f(s)

This multiplicative property means that equal time intervals remove equal fractions of what remains, rather than equal absolute amounts.

An observed first-order law need not be elementary

A bimolecular rate k₂[A][B] behaves approximately as kobs[A] if B is in such large excess that [B] barely changes; kobs = k₂[B]excess. This is pseudo-first-order kinetics. The exponential holds only while that approximation and the temperature remain adequate.
