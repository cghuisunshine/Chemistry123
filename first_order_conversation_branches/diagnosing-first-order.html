How do data test a first-order model?

What does a straight logarithmic plot establish?

Linearize a dimensionless ratio

ln(c/c₀) = −kt

A plot against t has slope −k and intercept zero when the chosen t = 0 and c₀ are exact. Taking ln c without a reference concentration is shorthand; an actual logarithm requires a dimensionless argument.

Prefer the original observable for fitting

A logarithmic plot is a useful diagnostic, but transforming noisy measurements changes the error distribution. When concentration errors are approximately additive, fit c(t) = c₀e−kt to the original values and inspect residuals. Persistent curvature or an offset can indicate a competing source, a background signal, or a changing rate constant.

Half-life and variable k

constant k: t½ = ln 2/k variable k: ln(c/c₀) = −∫0t k(t′) dt′

If temperature changes, the exponential with one constant k generally fails. A half-life then satisfies ∫k(t′)dt′ = ln 2 over the relevant interval, and successive halves need not take the same time.
